# Mission: Professional TypeScript in React

## Why

I already know React well enough to build real apps. But in professional environments, TypeScript is the standard — and I need to learn the patterns that teams actually use day-to-day.

## Goals

- Write React components with TypeScript confidently, using the same patterns as production codebases
- Understand typing props, state, events, refs, context, and custom hooks
- Know when to use `interface` vs `type`, generics, discriminated unions, and utility types
- Integrate TypeScript with React Router, forms, and data fetching
- Read and contribute to TypeScript React codebases without friction

## Non-Goals

- Learning React from scratch
- Deep TypeScript metaprogramming (e.g., complex conditional types)
- TypeScript outside the context of React

## Success Criteria

- Can build a production-grade React component library with full TypeScript support
- Can onboard onto any TypeScript + React codebase at work
- Can review PRs for TypeScript correctness in React apps
