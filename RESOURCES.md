# Resources

## Primary

### Official Docs
- [React TypeScript Cheatsheet](https://react-typescript-cheatsheet.netlify.app/) — The community-maintained definitive reference for TypeScript in React
- [TypeScript Handbook: JSX](https://www.typescriptlang.org/docs/handbook/jsx.html) — Official TS guide on JSX support
- [React Docs: Static Type Checking](https://react.dev/learn/static-type-checking) — React's official guide on TypeScript

### Books / Courses
- [Total TypeScript: Essentials](https://www.totaltypescript.com/) — Matt Pocock's TypeScript workshop (highly recommended for React devs)

### Video
- [Matt Pocock YouTube](https://www.youtube.com/@mattpocockuk) — Best TypeScript + React content on YouTube

## Community

- [Total TypeScript Discord](https://www.totaltypescript.com/discord) — Active community for TypeScript questions
- [/r/typescript on Reddit](https://www.reddit.com/r/typescript/) — General TypeScript discussions

## Tooling

- [TypeScript Playground](https://www.typescriptlang.org/play) — Experiment with TS types in the browser
- [Vite](https://vitejs.dev/) — Recommended build tool for new TS + React projects
