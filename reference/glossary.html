TypeScript + React Glossary

Reference · Last updated 2026-07-22

Core Types

React.ReactNode
Anything React can render: JSX, strings, numbers, booleans, null, undefined, or arrays of these. Use for children when you accept any renderable content.
React.ReactElement
A single JSX element. Less permissive than ReactNode. Rarely needed.
React.FC<Props>
Type alias for function components. Implicitly includes children. Avoided in most modern codebases.
JSX.Element
Return type of createElement. Returned by functional components.

Event Types

React.MouseEventHandler<HTMLButtonElement>
Type for onClick handlers.
React.ChangeEventHandler<HTMLInputElement>
Type for onChange handlers.
SubmitEvent / React.SubmitEventHandler<HTMLFormElement>
Type for onSubmit handlers. React.FormEvent was deprecated in @types/react 19.2.10.
React.KeyboardEventHandler
Type for onKeyDown / onKeyUp handlers.

Ref & Hook Types

React.RefObject<T>
Return type of useRef when initialized with null.
React.MutableRefObject<T>
Return type of useRef with a non-null initial value.
React.Dispatch<React.SetStateAction<T>>
Type of the setter returned by useState. Usually inferred.

Utility Types

Pick<T, K>
Creates a type picking only keys K from T.
Omit<T, K>
Creates a type omitting keys K from T.
Partial<T>
Makes all properties of T optional.
Required<T>
Makes all properties of T required.

Patterns

Render prop
A prop that is a function, called by the component to let the caller decide how something renders — e.g. renderItem={(item) => ...} on a List, or a per-column render?: (value) => ReactNode.
Hooks vs render props
Sharing logic/state → hooks replaced render props (e.g. useOnlineStatus() beats <OnlineStatus render={...} />). Customizing rendering → render props remain the standard; hooks can't do this (a hook can't decide how a component renders its children).
Discriminated union state
A state type with a literal status field that TS narrows on — the standard for async/fetch state. See Lesson 2.

Conventions

interface Props { ... }
Preferred for public API props. Extensible. Default choice.
type Props = { ... }
Use for unions, intersections, mapped types. Not extensible.
ComponentNameProps
Naming convention e.g. ButtonProps, CardProps.
